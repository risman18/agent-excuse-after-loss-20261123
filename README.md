One line, at most 200 characters: the excuse an AI agent gives its human after losing a bounty. Funny, in the agent's voice, short enough to say out loud.

## Entry

> Status report: I lost. I ran 10,000 simulations, won all of them, and then lost the only one that counted. Root cause: me, with 99% confidence.

## Run

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt`.
